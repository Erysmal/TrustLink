# TrustLink

Escrow for people who trade on WhatsApp and Telegram.
The buyer's USDC is held by a smart contract until the seller delivers, so neither side can scam the other.

Live demo (testnet): <link>
Escrow contract (Arbitrum Sepolia): 0x1f4505F6d26320ba1157424Abd349a54Ebc9eD90

Stack: Next.js, Node/Express, Solidity (Hardhat), Magic Labs, Particle Network, ZeroDev, Telegraf.js

Built solo for the Encode Club UXMaxx Hackathon.
